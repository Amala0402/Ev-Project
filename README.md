⚡ Electric Vehicle Nearest Charging Station Locator


A simple and interactive web project that helps users instantly find the nearest EV charging stations using Google Maps. Designed with a clean interface, responsive layout, and engaging visuals, it makes electric mobility easier and smarter for users.


💡 Features

✅ Responsive Navigation Bar with Home, About, Services, Login & Profile

📍 Integrated Google Map to display nearby EV charging stations in real time

📹 Video Section to visually explain project features

🚘 Smart EV Features – Station Availability, Route Planning, and Usage Tracking

💬 Contact Form for user queries and feedback

📱 Fully Responsive design for mobile, tablet, and desktop


🛠️ Tech Stack

Frontend: HTML5, CSS3

API: Google Maps Embed

Design: Responsive layout using CSS Flexbox & Grid
